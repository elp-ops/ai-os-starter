# Brainstorms

Raw capture files from `/grill-me` sessions live here, one file per topic: `{YYYY-MM-DD}-{topic-slug}.md`.

This is where a plan, a design, or an idea gets interviewed out of your head and checkpointed to disk as you go, so nothing gets lost mid-session. If a session later produces a polished deliverable (a plan, a spec, a finished doc), that artifact can move into the relevant `projects/` folder, but the raw capture always stays here.
